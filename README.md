### Project Description
A Java console application that simulates a user registration and login system. The program validates the username and password against the requirements specified in the PROG5121 FA1 brief and provides feedback to the user.

This project demonstrates core Java concepts including methods, selection statements, string handling, and boolean logic.

### Functional Requirements Implemented

**1. Username Requirements**
- Must contain an underscore `_`
- Must not exceed 5 characters
- Message if correct: `Username successfully captured`
- Message if incorrect: `Username is not correctly formatted, please ensure that your username contains an underscore and is no more than 5 characters in length.`

**2. Password Requirements**
- At least 8 characters long
- At least one capital letter
- At least one number
- At least one special character
- Message if correct: `Password successfully captured`
- Message if incorrect: `Password is not correctly formatted, please ensure that the password contains at least 8 characters, a capital letter, a number and a special character.`

**3. Core Methods**
- `checkUserName()`
- `checkPasswordComplexity()`
- `registerUser()`
- `loginUser()`
- `returnLoginStatus()`
